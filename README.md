# ChatBot
A lightweight AI-powered chatbot built using Streamlit and LangChain, integrated with Hugging Face's Mixtral-8x7B-Instruct model. The chatbot is designed to give concise, accurate, and context-aware responses — maintaining conversation history naturally and providing clear answers in minimal lines.


Features

- Interactive Chat UI built with Streamlit

- Context-aware conversation using LangChain’s ChatHuggingFace interface

- Powered by Mixtral-8x7B-Instruct model from Hugging Face

- System prompt tuning for concise and coherent replies

- Environment variable management using .env and python-dotenv

- Session-based memory to maintain chat history between messages

 # Tech Stack

- Python 3.10+

- Streamlit – for frontend interaction

- LangChain – for model orchestration

- Hugging Face Hub – for large language model inference

- dotenv – for API key handling
